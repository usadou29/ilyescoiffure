# Ilyes Coiffure

Site vitrine premium pour le salon de coiffure Ilyes Coiffure à Étampes.

## 🎯 Objectif

Ce site a été créé comme démonstration commerciale pour présenter une version moderne et professionnelle du site web du salon.

## ✨ Caractéristiques

- **Design premium** : Interface moderne avec une identité visuelle masculine et élégante
- **Responsive** : Adapté à tous les écrans (mobile, tablette, desktop)
- **Performant** : Développé avec Vite pour des performances optimales
- **SEO-friendly** : Structure sémantique et meta-tags optimisés

## 🛠 Stack Technique

- **React 19** - Bibliothèque UI
- **Vite 6** - Build tool rapide
- **Tailwind CSS 4** - Framework CSS utilitaire
- **Lucide React** - Icônes modernes

## 🚀 Installation

```bash
# Cloner le repository
git clone https://github.com/usadou29/ilyescoiffure.git

# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev

# Build pour production
npm run build
```

2. **Présentation** - Description du salon et de son expertise

4. **Horaires** - Horaires d'ouverture et statut en temps réel

6. **Contact** - Informations de contact et CTA
